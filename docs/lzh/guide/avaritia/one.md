# 置之指南

一、 **取插件**: 於發布之頁取最新之 `Avaritia_Plugin.jar`。
二、 **置之**: 將所取之 `.jar` 檔置於汝服之 `plugins` 資料夾中。
三、 **啟服**: 啟或重啟汝之 Minecraft 伺服器。
四、 **生策**: 插件初啟後，將於 `/plugins/Avaritia_Plugin/` 目錄下生所有必需之策。
五、 **定策**: 依汝所需，編[要策](./amainconfig.md)及其他相關之策。
六、 **重載**: 於戲中或臺上用 `/avaritia reload` 號令以使汝之策效。
