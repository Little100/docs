# 此乃插件之號令，僅述其要者。
> 吾將以OP與非OP之權分述之。

## 號令之本
 - 令有二，可供驅使。
 - 其令曰：
   - `/pe`
   - `/projecte`

# OP之令
## reload
 - 用以重啟插件（將復計EMC之值）。
## setemc
 - 用以設定物之EMC值（手中之物）。
 - 用法：前令 + setemc <EMC之值>
## noemcitem
 - 用以察EMC為零之物（即無EMC者）。
## pdcitem
 - 用以察所有PDC之物之EMC。
## table
 - 使爾之轉換桌頓悟萬物。
 - 用法：前令 + table learn
## lang
 - 用以更易語言。
 - 用法：前令 + lang <語言之檔>

# 非OP之令
## pay
 - 用以予玩家EMC。
 - 用法：前令 + pay <玩家名> <EMC之值>
## bag
 - 用以察鍊金術之袋之表。
 - 用法：前令 + bag + list
