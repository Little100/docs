# 安装指南

1.  **下载插件**: 从发布页面下载最新版本的 `Avaritia_Plugin.jar` 文件。
2.  **放入插件文件夹**: 将下载的 `.jar` 文件放入你服务器的 `plugins` 文件夹中。
3.  **启动服务器**: 启动或重启你的 Minecraft 服务器。
4.  **生成配置文件**: 插件首次启动后，会在 `/plugins/Avaritia_Plugin/` 目录下生成所有必需的配置文件。
5.  **配置插件**: 根据你的需求，编辑[主配置文件](./amainconfig.md)以及其他相关配置。
6.  **重载插件**: 在游戏内或控制台使用 `/avaritia reload` 命令来应用你的配置更改。
