# 主配置文件 (`config.yml`)

这是 Avaritia 插件的核心配置文件，你可以在这里调整插件的各项基本功能。

## 全局设置

### `debug`

- **类型**: `布尔值 (true/false)`
- **默认值**: `false`
- **说明**: 是否开启插件的 Debug 模式。开启后，控制台会输出详细的调试信息，用于排查问题。

### `default_language`

- **类型**: `字符串`
- **默认值**: `"zh_cn"`
- **说明**: 设置插件默认使用的语言文件。

## 方块设置

### `allow_place_block`

- **类型**: `布尔值 (true/false)`
- **默认值**: `false`
- **说明**: 是否允许玩家放置压缩工作台、二重压缩工作台和水晶矩阵。
  - `false`: 禁止放置这些方块。
  - `true`: 允许放置，并会像终极工作台一样使用盔甲架来显示模型。

### `compressor_protect`

- **类型**: `布尔值 (true/false)`
- **默认值**: `false`
- **说明**: 设置破坏中子态素压缩机时的掉落行为。
  - `false`: 仅掉落压缩机本身，内部物品和进度会丢失（与原版模组行为一致）。
  - `true`: 破坏时，会将内部正在处理的物品按进度转换为低阶材料掉落（例如，正在压缩的钻石块会掉落为钻石）。

## 终极工作台 (`extreme_crafting_table`)

### `debug`

- **类型**: `布尔值 (true/false)`
- **默认值**: `false`
- **说明**: 终极工作台的合成 Debug 模式。
  - `true`: 开启后，将无视合成配方，放入任意材料都能合成物品，主要用于快速测试。
  - `false`: 正常检查合成配方。

## 无尽工具 (`infinity_tools`)

### `hammer_break_bedrock`

- **类型**: `布尔值 (true/false)`
- **默认值**: `false`
- **说明**: 设置世界崩解之镐的锤子模式是否能够破坏基岩。为了保护服务器，默认为关闭。

### `hammer_cmd`

- **类型**: `整数`
- **默认值**: `101`
- **说明**: 设置锤子模式物品的 CustomModelData (CMD) 值，用于资源包更换其材质。

### `skullfire_offhand_transfer`

- **类型**: `布尔值 (true/false)`
- **默认值**: `true`
- **说明**: 设置副手持有骷髅剑时的效果。
  - `true`: 当副手持有骷らなかった剑时，主手使用任何武器击杀凋灵骷髅都有 100% 的几率掉落头颅。
  - `false`: 只有直接使用骷髅剑击杀时才会触发头颅掉落。
