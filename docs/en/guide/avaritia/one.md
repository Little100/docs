# Installation Guide

1.  **Download the plugin**: Download the latest version of the `Avaritia_Plugin.jar` file from the release page.
2.  **Place it in the plugins folder**: Put the downloaded `.jar` file into your server's `plugins` folder.
3.  **Start the server**: Start or restart your Minecraft server.
4.  **Generate configuration files**: The plugin will generate all necessary configuration files in the `/plugins/Avaritia_Plugin/` directory on its first startup.
5.  **Configure the plugin**: Edit the [main config file](./amainconfig.md) and other relevant configurations to suit your needs.
6.  **Reload the plugin**: Use the `/avaritia reload` command in-game or in the console to apply your configuration changes.
