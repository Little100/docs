# OP Item Configuration

The Avaritia plugin includes some special items intended for server operators (OPs) only. These items are typically used for server administration, events, or testing, and should not be obtainable through normal gameplay.

## How to Obtain

All OP items can only be obtained via the `/avaritia give` command, which requires the `avaritia.give` permission (granted only to OPs by default).
