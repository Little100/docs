# OP 物品設定

Avaritia 插件包含一些特殊的、僅供管理員 (OP) 使用的物品。這些物品通常用於伺服器管理、活動或測試，不應透過正常遊戲途徑獲得。

## 獲取方式

所有 OP 物品都只能透過 `/avaritia give` 指令獲取，並且需要 `avaritia.give` 權限（預設僅 OP 擁有）。

## 物品列表

### 範例

#### 管理員之劍 (Admin_Sword)

- **ID**: `admin_sword`
- **描述**: 一把可以秒殺任何生物的劍，用於快速清理實體。
- **獲取指令**: `/avaritia give <玩家> admin_sword`

#### 創造者之星 (Creator_Star)

- **ID**: `creator_star`
- **描述**: 一個用於觸發特殊伺服器事件的物品。
- **獲取指令**: `/avaritia give <玩家> creator_star`
