# 安裝指南

1.  **下載插件**: 從發布頁面下載最新版本的 `Avaritia_Plugin.jar` 檔案。
2.  **放入插件資料夾**: 將下載的 `.jar` 檔案放入你伺服器的 `plugins` 資料夾中。
3.  **啟動伺服器**: 啟動或重啟你的 Minecraft 伺服器。
4.  **生成設定檔**: 插件首次啟動後，會在 `/plugins/Avaritia_Plugin/` 目錄下生成所有必需的設定檔。
5.  **設定插件**: 根據你的需求，編輯[主設定檔](./amainconfig.md)以及其他相關設定。
6.  **重載插件**: 在遊戲內或主控台使用 `/avaritia reload` 指令來套用你的設定變更。
